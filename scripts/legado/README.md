# Scripts legados

Estes scripts foram movidos da raiz para manter o projeto limpo. Eles são
referências do fluxo antigo de roteiro e renderização de animais abissais; o
fluxo ativo é o painel em `frontend/` com o backend em `backend/`.

Os caminhos internos foram ajustados para que possam ser executados a partir
desta pasta, por exemplo:

```powershell
python scripts/legado/renderizar_teste_animais.py
```
